影视内容生成工具集，覆盖从概念设计到成片的完整创作流程。

**TRIGGER when**: 用户请求生成图片、视频、音频或语音合成。

---

## 服务概览

| 服务 | 功能 | 典型场景 |
|------|------|---------|
| `文生图` | 文字→图片 | 概念设计、角色设计、分镜图 |
| `图生图` | 图片风格转换 | 概念图优化、风格统一 |
| `文生视频` | 文字→视频 | 场景素材、空镜视频 |
| `首尾帧` | 两图→过渡动画 | 变身特效、场景转换 |
| `语音视频` | 图片+音频→说话视频 | 数字人、虚拟主播 |
| `镜头控制` | 图片+镜头运动 | 推拉摇移、动态镜头 |
| `视频控制` | 图片模仿视频动作 | 动作复用、舞蹈迁移 |
| `语音合成` | 文字→配音 | 旁白配音、音色克隆 |

---

## 影视创作流程

```
前期筹备: 文生图 → 图生图 (概念/角色/分镜设计)
视频制作: 文生视频 / 首尾帧 / 镜头控制 / 视频控制
后期配音: 语音合成 / 语音视频
```
